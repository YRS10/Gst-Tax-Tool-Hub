How to use this tool (portal downloads and output guide)

Step 1: Download filed returns from the GST portal

  1. Open Services > Returns > Returns Dashboard and select the required GSTIN and return period.
  2. Download the filed GSTR-3B PDF for the monthly period from View Filed Return or the PDF/download option shown for the filed return.
  3. For GSTR-1, use Services > Returns > Returns Dashboard > GSTR-1 > Prepare Online / View Filed GSTR-1, then download or print the filed GSTR-1 as a PDF.
  4. If GSTR-1A is filed for the period, download the filed GSTR-1A PDF using the same return-period and view filed return options.
Important: download the filed/acknowledged PDFs, not the draft preview. PDFs must contain selectable text; scanned or image-only PDFs require OCR before upload.

Step 2: Upload the PDFs

  1. Drag and drop GSTR-3B, GSTR-1 and GSTR-1A PDFs into the upload area, or use Choose PDF files.
  2. Files of different GSTINs can be processed together. The workbook separates data by GSTIN and financial year.
  3. Processing is automatic. Review any unread or missing-table warnings before export.

Step 3: Review and export

  1. Use Preview table to check the extracted data matrix.
  2. Click Download Excel workbook. Annual totals appear before monthly rows in the data sheets.
  3. GSTR Reconciliation compares GSTR-3B Table 3.1 with GSTR-1 plus GSTR-1A; inward supplies under reverse charge are excluded. Difference rows are highlighted and bold.
  4. RCM Reconciliation compares GSTR-3B Table 3.1(d) (inward supplies liable to reverse charge) with Table 4A(3) (ITC on inward supplies liable to reverse charge, other than imports). Both reconciliation sheets are placed right after the Processing Log sheet in the workbook.
Review first: always compare the downloaded output with the filed GST portal returns before using it for reporting or compliance.

2. Review and export

Review extracted rows by return table, then export the complete workbook.

Your monthly data matrix will appear here after the PDFs are processed.

GSTR-1 and GSTR-1A worksheets include only the Total Liability row. The reconciliation compares GSTR-3B Table 3.1 (excluding inward supplies liable to reverse charge) with GSTR-1 plus GSTR-1A; financial-year totals appear before month-wise rows. If a GSTR-1 or GSTR-1A file is missing for a month, it is treated as nil so the difference is still shown. The RCM Reconciliation compares the tax amounts of GSTR-3B Table 3.1(d) with Table 4A(3); taxable value is not compared because Table 4 does not report it. GSTR-3B table worksheets retain their existing detail. Always reconcile extracted figures against the filed returns before using them for compliance or reporting.

3. Processing log

File-wise status of every PDF: files that could not be read (for example scanned/image-only PDFs that need OCR, password-protected or corrupted files), files where no values were captured, and missing details. The same log is exported as the "Processing Log" sheet.

File-wise processing results will appear here.
GSTR-1, GSTR-1A and GSTR-3B PDFs with selectable text are supported. Image-only PDFs (for example "Print to PDF" files) are read with built-in OCR, which is slower, so the log asks you to verify those figures.

What you get

Consolidates 24 transaction-sheet categories (B2B, B2BA, CDNR, ISD, IMPG, etc.) from any number of files, folders and GSTINs into one workbook, plus a Value Summary and a Summary/audit-trail sheet. Each row carries its Source File (with folder path), Financial Year, Tax Period, GSTIN and Legal Name; rows are grouped GSTIN-wise, then by month.

Invoices/notes amended in a later period (B2BA, B2B-CDNRA) replace their original rows, and the amended rows show the original tax period beside them. The "Amended Inv. Comparison" sheet lists each original invoice/note that was later amended with its original values, amended values and the difference (increase / decrease / newly reported in amendment).

Nothing is uploaded anywhere. All processing happens locally in this browser tab, using JavaScript libraries loaded from a CDN. The result is generated and offered to you as a download, with no network transfer of the actual data.
